# Personal Finance & Spending Behavior Analysis

## Project Overview

This project analyzes personal finance data
from 20,000 individuals in India to identify
income distribution, spending patterns,
and savings opportunities.

## Business Objectives

- Analyze income distribution.
- Understand monthly spending behavior.
- Compare spending across age groups.
- Evaluate savings goals.
- Identify potential cost optimization areas.

## Dataset

Source: Kaggle - Indian Personal Finance and Spending Habits

Author: Shriyash Jagtap

Records: 20,000 individuals
